# 版本修改记录（CHANGELOG）

记录了从初版到 v2.0 的全部修改，含每个 bug 的根因分析，供接手者避免重蹈覆辙。

## v1.0 — 初版
- 仿 slither.io：指针/方向盘转向、按住加速（燃烧长度掉食物）、9 条 AI、实时排行榜、击杀/复活、网格世界、圆形边界（撞边死亡）
- 验证：无头浏览器自动驾驶 88s 零报错；188s 经历 3 次阵亡-复活循环零报错

## v1.1 — 7 项修复
1. **大蛇卡顿/变慢**：身体渲染从逐点 arc（数百次/帧）改为整条 path 一次 stroke；碰撞采样步长按长度自适应；速度随视野缩放补偿
2. **食物过多**：环境食物 380 → 170
3. **尾巴自动掉方块**：根因 = 加速状态在部分触摸场景"粘住"不释放 → 重写加速按钮（Pointer capture + 松手清除）+ 保险逻辑
4. **撞边界死亡** → 改为贴边滑行（去除速度径向分量），永不死亡
5. **AI 太笨**：重写 aiThink（9 方向危险评估、躲大蛇、拦截小蛇、安全才加速）
6. 同 2
7. **加速按钮**：按住即冲、松开即停，加亮反馈

## v1.2 — 图标 + 两个长度 bug
- 新增应用图标（PIL 绘制：绿蛇 + 大眼睛 + 渐变圆角底，5 密度 + 自适应图标）
- **吃豆长度不加**：根因 = 每豆只 +0.9 分而长度整数取整 → 改为每豆必 +1（专项测试：首豆 26→27）
- **不吃豆长度自动减到 ~27**：根因 = 加速状态仍可粘住 → 改为**每帧根据"手指是否还按着"重算加速状态**（机制性根治）
- 验证：强制写入粘住状态，下一帧自动清除 ✓

## v1.3 — 蛇身跟随 + AI 转圈 + 巨蛇
- **蛇身不跟随蛇头**：跟随算法从"逐节点拉近"（弯道抄近路漂移）改为**记录蛇头历史轨迹、按弧长精确布点**
- **AI 原地转圈**：根因 = 恐慌半径（70px）过大到处皆危险 → 缩至 45px，加"保持方向加分 + 禁止原地掉头"
- **没有巨蛇**：开局 2 条大蛇（110/180）、AI 重生 25% 概率为大蛇（90-180）、寻食半径 650→900、每条蛇独立攻击性 aggro
- 加速消耗 0.13 → 0.10/帧
- 验证：135s 零报错，AI 最大长度 184→300+，平均 59→102

## v1.4 — 尾巴闪烁 + 起名选色
- **尾巴闪烁**：根因 = 加速连续扣分 + 长度整数取整 → 分数在整数边界抖动 → 尾节点反复长出/消失。修复：长度变化加迟滞（±1 分滞回）
- 开始界面新增：名字输入（≤8 字）+ 8 色皮肤选择

## v2.1 — 联机卡顿修复 + 蛇头对撞 + 小地图
- **联机玩一段时间后一顿一顿**：双根因。① Java 侧 `lanSend` 每条消息新建线程（快照 10Hz + 输入 30Hz ≈ 每秒 40 个线程，GC 抖动）→ 改为**单一写线程 + LinkedBlockingQueue(256)**，队列满时丢最旧保最新；② 快照随蛇长无限变大 → 采样步长按长度自适应（上限 160 点/蛇，强制包含尾点）、快照 10Hz→7.5Hz、输入 30Hz→20Hz、食物上报 130→100 个/半径 1700→1600
- **两条蛇交叉穿越互不死**：根因 = 碰撞只查"头 vs 对方身体第 8 节点之后"，头对头时互相穿过头部豁免区 → 新增**蛇头对撞判定**（头距 < (r1+r2)×0.6：分数大 1.15× 以上者胜，否则同归于尽）。新增 `__HEADTEST__` 仿真钩子（强制两 AI 头对头相向，断言 tick≤340 内必有死亡）✓
- **左下角小地图**：圆形雷达（摇杆上方），世界边界环 + 全部蛇位置点；自己 = 白圈大点，联机对方玩家 = 彩色环大点（快照新增 `h` 人类标记位），AI = 小点
- 验证：双实例联机仿真（sent=105 / recv=109、snakes=11 两端一致、sync=1、零错误）；67s 全项回归（吃豆/光环/对撞/视野/边界/上榜/复活）零报错
