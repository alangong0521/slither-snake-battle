## 三、使用方法

```bash
cd snake_apk
python3 tests/run_tests.py     # 全绿才能发布；任一 FAIL 退出码非零
```

依赖：Linux + chromium（headless）。测试页由脚本从当前 `app/src/main/assets/index.html`
动态生成（tests/.work/，已 gitignore），永远测的是最新代码，无需维护测试副本。

新增 Bug 修复时的约定：
1. 先在 tests/ 里加对应用例（编号顺延），复现失败；
2. 修复至通过；
3. 在本文档 Bug 档案表补一行；
4. CHANGELOG.md 记录版本变更；
5. index.html 的 `VERSION` 与 app/build.gradle 的 versionName 同步 +0.1，versionCode +1。
